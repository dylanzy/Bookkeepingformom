# 妈妈的记账本 v7

## v7 修复

主要修复了"买洋葱"、"买番茄"、"买排骨"、"买大米"等常见买菜场景没自动归类的问题。

**词表大幅扩充**:加了 100+ 常见食材关键词
- 蔬菜:洋葱、葱、番茄、辣椒、白菜、空心菜、菠菜、芹菜、韭菜、藕、豆腐 等
- 肉禽蛋:猪肉、牛肉、排骨、五花肉、鸡腿、鸡蛋 等
- 水产:虾、螃蟹、带鱼、鲫鱼、鲈鱼 等
- 水果:榴莲、芒果、火龙果、樱桃、葡萄、柚子 等
- 主食杂粮:大米、小米、面粉、花生、核桃 等
- 调味品:酱油、料酒、味精、八角、花椒 等

**精修了歧义词**:去掉了"鱼""肉""蛋""糖"等单字关键词(容易误匹配),改成"猪肉""鸡蛋""白糖"等明确词组。

20 个测试用例全过(包括"买洋葱9.9"和歧义场景如"给孙子买苹果"应归"家人"而非"买菜")。

## 部署

跟之前一样,直接覆盖部署:

```bash
cd 解压后的 v7 文件夹
npm install
netlify deploy --prod
```

环境变量不变。图标不变。

## 还有问题?

如果你妈说的某种食材规则还没覆盖到(比如某种地方特色菜):

1. 这条记账会先归"其他"
2. 然后触发 AI 兜底,大概率会被正确分类
3. AI 失败的话,你妈可以**点这条记录手动改成"买菜"** —— 改完后系统会"学习",下次再说同样的词会自动归对

如果发现某个词频繁失败,告诉我,我加进词表。
